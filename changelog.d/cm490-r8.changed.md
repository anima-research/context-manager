- Compression-quarantine checkpoint hygiene rechecks its source branch before
  appending, so a reentrant branch initialization cannot checkpoint an old
  branch's holds into the new branch. Keyed release reclassifies a lost load
  after projection reads before returning selection results or entering its
  uncertain mutation path. Branch guards also recheck the strategy generation
  after reentrant branch lookups. No new locks or cross-process guarantees.
