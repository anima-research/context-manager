- `acceptRound` checks each entry of a layout's `memberSequences`, not just their count: each must be a store sequence (a non-negative safe integer), and in a layout keyed by sequence each must be its member. A layout that breaks this is refused, writing nothing, with an error that names the first entry that does (`its memberSequences[1] is "zz", not a store sequence …`). Before, an equal-length array of anything was accepted, and a receipt's run could be bounded by an undefined or non-numeric `sequence`. A compile's provenance, accepted as compile returned it, always passes.
