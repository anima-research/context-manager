- `presentRows`, `retractRows`, `retractRemoved` and `retractAbsentRows` throw `WindowWriteOutcomeUnknownError`, a new export from the root, when the store throws on the window index's write and the index then can't be read again to tell whether the write landed. Before, they threw the write's own error, as for a write the store refused, the strategy never heard the rows such a write put in or took out, and a retry was refused or passed those rows over. The error carries the write's own error as its `cause`, the failed read's as `readError`, the call as `operation`, and the rows the write would have put in and taken out as `entering` and `leaving`; its message ends with the cause's message. The write is one record, so the store holds all of it or none of it, and `windowStatusOf` tells which once the index reads. The strategy hears what the write did (`onPresented`, `onRetracted`) at the next write to the window on the branch it was made on, `presentRows([])` among them, before that call's own work, and hears nothing of a write the store didn't keep.
