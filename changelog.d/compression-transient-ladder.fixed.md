- Transient provider failures no longer spend the L1 compression ladder or exhaust a request family. A failure is evidence about the request only when it is a deterministic rejection (`context_length`, `invalid_request`, `safety`, `unsupported`). Capacity, transport, credential and unclassified failures used to be recorded as a rung's `provider_error` while the ladder carried on, so an outage could quarantine a viable family. Now such a failure stops the ladder at that rung and keeps what the ladder had learned, and a later tick resumes there.
  - Durable family progress (branch-scoped state `autobio:compression-family-progress`, separate from the quarantine ledger): every deterministic answer a request has given is written and synced before the next rung's call, so neither a restart nor a resumed tick pays again for the canonical or for a rung whose outcome is known. It is dropped when the chunk mints or its debt is paid, and when the family exhausts into quarantine.
  - A request-attributable rejection of the canonical (including its no-tools or tools-less retries) skips the recall variants and the canonical hoist. Each variant reuses the rejected request and only expands recall. The rejection goes to source-only-final once, when configured, and otherwise exhausts the family.
  - A request's consecutive server errors are counted durably, and the 12th, the merge lane's bound, becomes that rung's deterministic outcome. Split-stitch is one atomic retry unit: a transient failure inside it re-runs the whole rung later, within its existing call caps.
- Compression is paced across ticks after a transient failure, in L1 or a merge. No compression call is made and no queue item is consumed until max(the provider's stated `retryAfterMs`, a local backoff of 30 s doubling to 10 minutes) has passed.
  - A stated wait is never shortened. One that is not finite pauses the lane until a restart or a model change.
  - Any provider answer resets the pause.
  - The pause is in process and scoped to the membrane instance and compression model: another model ignores and clears it. A restart-stable provider deadline belongs to the caller's provider admission. Discarded or stale-branch work installs nothing.
  - One warning per pause, a `compression:lane-paused` log event, and `checkReadiness()` names the pause while it lasts.
- The merge lane routes only request-attributable rejections through its bounded attempt policy. A non-retryable failure that says nothing about the request (an expired key, a spent quota) now pauses the lane instead of spending attempts toward quarantine. Server errors still count toward the persisted 12-failure bound.
- Compression failure logs (`Failed to compress chunk`, `Failed to merge summaries`, the speculative-drain error) print a bounded string instead of the error object. A provider error's `rawRequest` is the whole request that failed, and printing the object wrote it out in full.
