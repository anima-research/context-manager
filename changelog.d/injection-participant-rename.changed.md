`compile()` now tags synthesized context messages with participant `system_context:{namespace}` instead of `injection:{namespace}`. The old name leaked verbatim into the rendered prompt (membrane formats messages as `{participant}: {text}`), and a speaker literally named "injection" tripped models' prompt-injection wariness on benign ambient context. Nothing keys off the prefix programmatically; transcripts and UI filters that grep for `injection:` should switch to `system_context:`.
