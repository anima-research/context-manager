- `branchAt(messageId)` finds a row of an auxiliary slot too, where it threw `Message not found` before (agent-framework #291). Once a host presents rows on the branch (`presentRows`), a row is in the window only from the write that presented it, so for a row the window holds the branch is cut at that write, the last of its body's shards, rather than at the row's own sequence. The new branch's window then holds the row and every row presented before it. Rows stored after the row and not presented by then are in the new branch's record, arrived and not presented. A row the window doesn't hold, and every row in legacy mode, is cut at its own sequence, as before.
