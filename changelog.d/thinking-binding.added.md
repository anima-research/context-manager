- `SelectOptions.prefixIdentity`: the host's identity for what it sends before the compiled messages (its system prompt and tools). It seeds the thinking-binding chain with the system injections the compile returns, so a change to either strips the thinking minted before it. A host that leaves it out has only the system injections in the seed, so a change to its system prompt or tools goes unseen.
- `SelectOptions.bindsThinking` (default `true`): whether the model a compile is sent to binds signed thinking to the prefix it was minted under. Set it `false` for a model that keeps such a block: that compile sends thinking as stored, and `AutobiographicalStrategy` renders its live window as configured. Stamping goes on either way. Measured on 2026-10-11 on one Anthropic account: Opus 5.5, Haiku 5.5, Sonnet 5.5 and Fable 5.1 bind thinking to its prefix; Fable 5 and Sonnet 5 keep it. If a model set `false` starts binding, an enforcing account refuses the first request that sends a block under a changed prefix: this setting is the one to check.
- `CompileResult.thinkingStripped`: the thinking blocks the pass removed from what the strategy rendered. It rises at a fold and once when the pass engages, and stays above zero only while something keeps invalidating replies, such as a positional injection.
- `CompileProvenance.dryRun`: set on a dry compile's provenance. `acceptRound` refuses it with a warning and records nothing, since no round carries a dry compile.
- Strategy hooks: `noteStrippedTokens(tokens)` reports the estimated thinking a committing compile priced but didn't send, for calibration (`AutobiographicalStrategy` takes it out of its sample), and `noteThinkingBound(bound)` says, before each compile's select, whether that compile's thinking is bound.
- `ContextManager.releaseThinking(messageId, fromBlock = 0)`: stop sending a stored message's thinking on the current branch, from that block on, for a block the provider refused (an altered signature, or one bound to another conversation), which every request would otherwise send again. The strategy's view reads the message without it from the next compile, as after the pass's own release. The branch's next accepted compile records it, so a restart before then loses it, and the host releases it again when the provider refuses it again. A branch made by `fork` or `branchAt` starts with the releases of the branch it was made from.
