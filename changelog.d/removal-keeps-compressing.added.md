- `MessageStore.held(id)` says whether the store ever held a message under an id, on any of its branches: true for a live message, for one removed since and, through a filtered view, for one the filter hides; false for an id it never gave a message. `MessageStoreView` gains it as an optional `held?(id)`, which `filterMessageStoreView` passes through, and `mergeMessageStoreViews` too when every view it merges has it.
- `MessageStore.onBranch(id)` says whether the current branch's messages chain holds the message an id names: true for a live message, for one removed since and for one the branch inherited through a fork; false for one another branch wrote after the fork, for one in a chain a lost state index left behind, and for an id it never gave a message. A message not in the listing costs one reconstruction of the messages state as it stood at its append. `MessageStoreView` gains it as an optional `onBranch?(id)`, passed through as `held?(id)` is.
