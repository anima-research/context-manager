- **Hosts and packages that install context-manager:** it now depends on `@animalabs/chronicle` `^0.6.0` (was `^0.5.0`). The window index writes a write-down, the rows of one `presentRows` call and the tombstones of one call as one record, through chronicle's identity-stamped batched append, `appendManyToStateJsonWithIdentity` (see the window index and window batches entries), and the published chronicle 0.5.0 has none of the batched calls (`appendManyToStateJson`, `appendManyToStateJsonWithIdentity`, `getStateItemsJson`, `getRecords`): chronicle releases them as 0.6.0. The window index has no one-record-per-row path. So a manager made over a store handle without the batched append is refused: `ContextManager.open({ store })`, `derive()` and `reopenDerived()` throw `ContextManager: the store handle has no appendManyToStateJsonWithIdentity, …` before any record changes, in legacy mode too. Asked at a write instead, a removal of two or more presented rows would have changed the record before its tombstones' batched write could throw, leaving their ordinals issued with only a log line to say so.
  **Who needs to act:** a host or package that depends on chronicle itself, such as agent-framework and connectome-host, which takes `^0.6.0` alongside this release so that npm installs one chronicle for both; and a host that opens its own `JsStore` and passes it as `store`, whose handle must come from chronicle 0.6.0 or later, whether or not it presents.
  **Migration:** install `@animalabs/chronicle` 0.6.0, once it is published, with this release. Until then an install from the registry doesn't resolve, and the lock file, which still names 0.5.0, is regenerated once it is (`npm install`, then `npm ci` checks it); a host that presents needs a chronicle built from chronicle's presentation branch, which has the batched calls.
  **Unchanged:** a manager that never presents (legacy mode) writes nothing to the window index, though it too needs a handle with the batched append to open. The store views `derive()` reads came with chronicle 0.5.0, in 0.24.0.
