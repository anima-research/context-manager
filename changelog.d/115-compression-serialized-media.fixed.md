- Compression prompts (L1, source-only fallback, merge) replace serialized `data:<mime>;base64,…` URLs of 4096+ base64 chars inside text blocks with a marker naming the media type and size. Imported tool output can carry a whole image as text, which the image-byte cap cannot see and the tokenizer prices as prose, so one image could become hundreds of thousands of tokens. Only the prompt changes; Chronicle is never mutated.
