- `WindowedPassthroughStrategy.setAnchor(sequence)` converts the sequence again once a re-anchor on overflow or `setAnchorOrdinal` has moved the anchor, even where the row the anchor moved to was stored at that same sequence. Before, it returned early whenever the sequence equalled the anchor's, so a tune-out's start set again after a re-anchor to a row stored at it, one taken out and presented again later, kept the window at that row and left out the rows presented between. The slot records such a move as `moved: true` beside `{ anchor, ordinal, v: 2 }`, so a restart converts too; `setAnchor` clears it, and the same sequence set again after that changes nothing, as before.
